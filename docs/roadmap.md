# Roadmap

The roadmap below reflects the current architecture and separates the implemented foundation from the planned product layers.

## Level 0 — Foundation ✅

Completed foundation work includes:

- repository scaffolding for a TypeScript monorepo
- workspace configuration with pnpm
- initial application, package, docs, and examples structure
- starter packages for scanner and shared logic

## Level 1 — Project Scanner

Planned work:

- inspect repository structure
- detect common technologies and frameworks
- produce a structured scan result for a project

## Level 2 — Project Graph

Planned work:

- build a graph of files, modules, and relationships
- capture structural context for deeper analysis

## Level 3 — Concept Usage

Planned work:

- identify important concepts used in the codebase
- connect those concepts to developer learning needs

## Level 4 — Developer Profile

Planned work:

- model developer interests, experience, and goals
- provide a basis for contextual guidance

## Level 5 — Gap Engine

Planned work:

- identify missing understanding or skill gaps
- compare known concepts against project context

## Level 6 — Learning Recommendation

Planned work:

- recommend relevant learning paths and topics
- connect recommendations to the project being explored

## Level 7 — Explain Engine

Planned work:

- explain unfamiliar code and architectural decisions
- provide contextual guidance grounded in the project

## Level 8 — Learning Progress

Planned work:

- track what the learner has explored and understood
- support ongoing, project-aware learning journeys

## Level 9 — Today Goal

Planned work:

- help developers focus on the next useful objective
- connect short-term goals to the current repository state

## Level 10 — First MVP

Planned work:

- unify the foundation layers into a first usable experience
- deliver a minimal end-to-end learning workflow for early adopters
